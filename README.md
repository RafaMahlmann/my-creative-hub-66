# My Digital Space

Eu tô pensando na possibilidade de criar um, um outro projeto paralelo aí, que é um só-- apenas um site do meu perfil, com foto, aí lá, por link de e-mail. Eu já tenho uma página minha, né? Por meus links de Instagram, YouTube, redes sociais, Facebook, aí deixar espaço pra umas materiazinhas que eu escrevo, ele publica, talvez um blog, alguma coisa assim. Hã, quantos créditos será que eu gastaria mais ou menos montando um negócio desses? O que que cê acha?
